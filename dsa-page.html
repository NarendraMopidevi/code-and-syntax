Introduction to DSA

What is DSA?
DSA stands for Data Structures and Algorithms. It is one of the core pillars of computer science and programming. DSA helps you answer two big questions:

  1. How should I store and organize data? → Data Structures
  2. How should I process that data step‑by‑step? → Algorithms

Data Structures: How Data is Organized

A data structure is a way of storing, organizing, and managing data so that it can be accessed and modified efficiently. Different structures are optimized for different operations:

  • Arrays: A simple list of elements stored in contiguous memory. Fast to access by index, but fixed or harder to resize.
  • Linked Lists: A sequence of nodes, each containing data and a pointer to the next node. Easy to insert/delete in the middle, but slower to access by index.
  • Stacks and Queues:
    • Stack follows LIFO (Last In, First Out), used in function calls, undo‑redo, and recursion.
    • Queue follows FIFO (First In, First Out), used in scheduling, breadth‑first search, and task management.
  • Trees and Graphs:
    • Trees are hierarchical structures (like a family tree or file system). Binary Search Trees allow fast searching and sorting.
    • Graphs model networks and relationships (social networks, maps, circuit diagrams).
  • Hash Tables / Maps: Store key‑value pairs and allow very fast lookup, insertion, and deletion on average.

Choosing the right data structure often decides whether your program runs in milliseconds or seconds.

Algorithms: Step‑by‑Step Problem Solving

An algorithm is a clear, finite set of instructions that solves a specific problem or performs a task. For example:

  • Sorting algorithms arrange elements in order (ascending or descending).
  • Searching algorithms find a particular element in a data set.

Algorithms are usually described in a language‑independent way, but then implemented in a real programming language like Java or Python.

Common algorithmic ideas include:

  • Iteration (loops)
  • Recursion (functions calling themselves)
  • Divide‑and‑conquer (split a problem into smaller sub‑problems)
  • Greedy methods (always choose the best immediate option)
  • Dynamic programming (break problems into overlapping sub‑problems and reuse results)

Why Time and Space Complexity Matter

To compare different algorithms, we use time complexity and space complexity, usually expressed using Big‑O notation.

  • Time complexity tells how the running time grows as the input size increases.
  • Space complexity tells how much extra memory the algorithm uses.

Examples:

  • O(n): Linear time; time grows linearly with input size.
  • O(n²): Quadratic time; common in simple nested loops.
  • O(log n): Logarithmic time; very fast; common in binary search.
  • O(1): Constant time; does not depend on input size.

A good DSA mindset is:
“Which structure and algorithm together give the best time and space trade‑off for this problem?”

What DSA Is Used For

DSA is not just theory; it powers real‑world software:

  • Search and sorting in databases, search engines, and e‑commerce.
  • Caching and networking using queues, stacks, and hash tables.
  • Graph algorithms in GPS navigation, social networks, and recommendation systems.
  • Machine learning and AI for efficient data structures under the hood.

Arrays

An array is a fixed‑size collection of elements stored in contiguous memory. Each element is accessed using an index, starting from 0. Arrays are one of the simplest and most widely used data structures.

Declaring and Initializing Arrays

You can create and initialize arrays in several simple ways:

Array Declaration & Initialization 
// 1. Declare then allocate
int[] arr1;
arr1 = new int[5]; // 5 elements, all 0 by default

// 2. Declare and allocate in one line
int[] arr2 = new int[4];

// 3. Initialize with values
int[] arr3 = {10, 20, 30, 40, 50};

// 4. Two-dimensional array (matrix)
int[][] matrix = {{1, 2}, {3, 4}};

// 5. Access by index
System.out.println(arr3[0]); // 10
System.out.println(arr3[2]); // 30

Common Uses of Arrays

Arrays are frequently used in basic algorithms and interview problems:

  • Storing lists of numbers, strings, or objects.
  • Implementing sorting and searching algorithms.
  • Building 2D grids or matrices (like graphs or game boards).
  • Dynamic programming tables (1D or 2D).

Key Limitations (Interview Mindset)

  • Size is fixed once created; you cannot change it directly without copying.
  • Access by index is O(1), but inserting/deleting in the middle takes O(n).
  • Reading or writing outside the valid index range causes an out‑of‑bounds error.
  • For problems that need frequent insertions or dynamic sizing, a different structure (like a list) is usually better.

Arrays: Practice Problem

Here is a simple DSA‑style array problem you can solve to strengthen your understanding of indexing and loops.

Problem: Find Maximum Element in an Array

Given an array of integers, write a function to find and return the largest element.

Find Maximum Element 
int findMax(int[] arr) {
    if (arr.length == 0) return -1; // or throw an exception

    int max = arr[0];
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}

Explanation (Interview Mindset)

We start by assuming the first element is the maximum. Then we iterate through the rest of the array, updating max whenever we encounter a larger element. This approach runs in O(n) time and uses constant extra space, which is optimal for this problem.

Linked Lists

A linked list is a linear data structure where each element (called a node) contains data and a reference to the next node. Unlike arrays, nodes are not stored in contiguous memory; they are linked by pointers.

Why Use Linked Lists Instead of Arrays?

Linked lists are preferred over arrays when:

  • You need frequent insertions or deletions in the middle of the list.
  • The size is unknown or changes often; you don’t want to copy everything when resizing.
  • You want flexible memory usage, allocating only what you need.

The trade‑off is that linked lists are slower to access by index because you must traverse the list from the head.

Linked List vs Array (Quick Comparison)

In interviews, you should know when to prefer each structure:

Aspect Array Linked List
Memory layout Contiguous blocks Nodes scattered; linked by pointers
Size Fixed size at creation Dynamic; grows/shrinks as needed
Insert/delete middle O(n) (shift elements) O(1) if position is known
Access by index O(1) (fast) O(n) (must traverse)
Memory efficiency May waste space if over‑allocated Uses only needed memory

Use arrays when you need fast random access and know the size. Use linked lists when you need frequent insertions/deletions and dynamic size.

Common Linked List Operations

Basic operations on a singly linked list:

  • Traverse: Visit each node from head to tail (time: \(O(n)\)).
  • Insert: - At head: fast, \(O(1)\). - At middle or tail: \(O(n)\) on average (traverse to position).
  • Delete: Remove a node by updating pointers (time: \(O(n)\)).
  • Search: Look for a value by scanning nodes (time: \(O(n)\)).
  • Reverse: Flip the pointers so the list runs backwards (time: \(O(n)\); common interview question).

Simple Linked List Node Code

Here is a minimal node and list skeleton you can use as a base for linked‑list problems:

Linked List Node 
import java.util.Scanner;

class Node {
    int data;
    Node next;

    public Node(int data) {
        this.data = data;
        this.next = null;
    }
}


public class LinkedList {

    private Node head;

    // Insert at the beginning
    private void insertAtBeginning(int data) {
        Node newNode = new Node(data);
        newNode.next = head;
        head = newNode;
    }

    // Insert at the ending (tail)
    private void insertAtEnding(int data) {
        Node newNode = new Node(data);
        if (head == null) {
            head = newNode;
            return;
        }

        Node temp = head;
        while (temp.next != null) {
            temp = temp.next;
        }
        temp.next = newNode;
    }

    // Insert after a node with given value (insert after target)
    private void insertByValue(int data, int target) {
        if (head == null) {
            System.out.println("List is empty");
            return;
        }

        Node temp = head;
        while (temp != null && temp.data != target) {
            temp = temp.next;
        }

        if (temp == null) {
            System.out.printf("%d is not found in the list%n", target);
            return;
        }

        Node newNode = new Node(data);
        newNode.next = temp.next;
        temp.next = newNode;
        System.out.printf("Inserted %d after %d%n", data, target);
    }

    // Insert at a given index (0‑based; valid indices: 0 to length)
    private void insertAtPosition(int data, int position) {
        if (position < 0) {
            System.out.println("Invalid position");
            return;
        }

        if (position == 0) {
            insertAtBeginning(data);
            return;
        }

        Node temp = head;
        for (int i = 0; temp != null && i < position - 1; i++) {
            temp = temp.next;
        }

        if (temp == null) {
            System.out.println("Position out of range");
            return;
        }

        Node newNode = new Node(data);
        newNode.next = temp.next;
        temp.next = newNode;
        System.out.printf("Inserted %d at position %d%n", data, position);
    }

    // Delete at the beginning
    private void deleteBeginning() {
        if (head == null) {
            System.out.println("List is empty");
            return;
        }
        head = head.next;
        System.out.println("First node deleted");
    }

    // Delete at the ending
    private void deleteEnd() {
        if (head == null) {
            System.out.println("List is empty");
            return;
        }

        if (head.next == null) {
            head = null;
            System.out.println("Last node deleted (now list is empty)");
            return;
        }

        Node temp = head;
        while (temp.next.next != null) {
            temp = temp.next;
        }
        temp.next = null;
        System.out.println("Last node deleted");
    }

    // Delete node at a given position (0‑based)
    private void deleteAtPosition(int position) {
        if (head == null || position < 0) {
            System.out.println("Invalid position or empty list");
            return;
        }

        if (position == 0) {
            deleteBeginning();
            return;
        }

        Node temp = head;
        for (int i = 0; temp != null && i < position - 1; i++) {
            temp = temp.next;
        }

        if (temp == null || temp.next == null) {
            System.out.println("Position out of range");
            return;
        }

        temp.next = temp.next.next;
        System.out.printf("Node at position %d deleted%n", position);
    }

    // Delete node with given value (first occurrence)
    private void deleteByValue(int target) {
        if (head == null) {
            System.out.println("List is empty");
            return;
        }

        if (head.data == target) {
            deleteBeginning();
            return;
        }

        Node temp = head;
        while (temp.next != null && temp.next.data != target) {
            temp = temp.next;
        }

        if (temp.next == null) {
            System.out.printf("%d is not found in the list%n", target);
            return;
        }

        temp.next = temp.next.next;
        System.out.printf("Node with value %d deleted%n", target);
    }

    // Reverse the linked list
    private void reverse() {
        if (head == null || head.next == null) {
            return;
        }

        Node prev = null;
        Node curr = head;

        while (curr != null) {
            Node next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }

        head = prev;
        System.out.println("List reversed");
    }

    // Display the list
    private void display() {
        if (head == null) {
            System.out.println("List is empty!");
            return;
        }

        System.out.print("List elements: ");
        Node temp = head;
        while (temp != null) {
            System.out.printf("%d -> ", temp.data);
            temp = temp.next;
        }
        System.out.println("Null");
    }


    public static void main(String[] args) {
        LinkedList list = new LinkedList();
        Scanner inp = new Scanner(System.in);
        int choice, data;

        do {
            System.out.println("\nLinked List Operations");
            System.out.println("\t1. Insert at Beginning");
            System.out.println("\t2. Insert at Ending");
            System.out.println("\t3. Insert by Position");
            System.out.println("\t4. Insert by Value (after target)");
            System.out.println("\t5. Delete Beginning");
            System.out.println("\t6. Delete Ending");
            System.out.println("\t7. Delete by Position");
            System.out.println("\t8. Delete by Value");
            System.out.println("\t9. Reverse List");
            System.out.println("\t0. Print List");
            System.out.println("\t10. Exit");
            System.out.print("Enter your option: ");

            choice = inp.nextInt();

            switch (choice) {
                case 1:
                    System.out.print("Enter element to insert at the beginning: ");
                    data = inp.nextInt();
                    list.insertAtBeginning(data);
                    break;

                case 2:
                    System.out.print("Enter element to insert at the ending: ");
                    data = inp.nextInt();
                    list.insertAtEnding(data);
                    break;

                case 3:
                    System.out.print("Enter element to insert: ");
                    data = inp.nextInt();
                    System.out.print("Enter position (0‑based): ");
                    int pos = inp.nextInt();
                    list.insertAtPosition(data, pos);
                    break;

                case 4:
                    System.out.print("Enter target to insert after: ");
                    int target = inp.nextInt();
                    System.out.print("Enter element to insert after " + target + ": ");
                    data = inp.nextInt();
                    list.insertByValue(data, target);
                    break;

                case 5:
                    list.deleteBeginning();
                    break;

                case 6:
                    list.deleteEnd();
                    break;

                case 7:
                    System.out.print("Enter position to delete (0‑based): ");
                    pos = inp.nextInt();
                    list.deleteAtPosition(pos);
                    break;

                case 8:
                    System.out.print("Enter value to delete: ");
                    data = inp.nextInt();
                    list.deleteByValue(data);
                    break;

                case 9:
                    list.reverse();
                    break;

                case 0:
                    list.display();
                    break;

                case 10:
                    System.out.println("Exiting...");
                    break;

                default:
                    System.out.println("Invalid choice");
            }

        } while (choice != 10);

        inp.close();
    }
}

This basic structure is enough to implement insert, delete, search, and reverse logic for most DSA‑style linked list problems.

Stack

A stack is a LIFO (Last‑In, First‑Out) data structure where elements can be added or removed only from the top. Stacks are widely used in function calls, recursion, undo‑redo systems, and expression evaluation.

Why Use a Stack?

Stacks are useful when:

  • You need to process the most recently added element first.
  • You are tracking nested or recursive operations (function calls, brackets, HTML tags).
  • You are doing depth‑first search (DFS), backtracking, or expression parsing.

Stack using List / Array 

import java.util.Scanner;

class StackArray {
    private final int[] stack;
    private int top;
    private final int stackSize;

    public StackArray(int size) {
        stack = new int[size];
        stackSize =size;
        top = -1;
    }

    public void push(int ele) {
        if(top == stackSize - 1) {
            System.out.println("stack us overflow");
            return;
        }
        stack[++top] = ele;
    }

    public int pop() {
        if(isEmpty()) {
            System.out.print("Stack is underflow");
            return -1;
        }
        System.out.printf("Poped element is %d\n", stack[top]);
        return stack[top--];
    }

    public boolean isEmpty() {
        return top == -1;
    }

    public void peek() {
        if(isEmpty()) {
            System.out.println("stack is underflow");
            return;
        }
        System.out.printf("\nelement at the peek is %d", stack[top]);
    }

    public void printStack() {
        if(isEmpty()) {
            System.out.println("Stack is underflow");
            return;
        }
        for(int i = top; i >= 0; i--) {
            System.out.printf("\n[%d] -> %d", i, stack[i]);
        }
        System.out.println();
    }
    public static void main(String args[]) {
        int choice;
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter size of the Stack : ");
        int size = sc.nextInt();
        StackArray stack = new StackArray(size);
        System.out.println("1. Push\n2. Pop\n3. Display\n4.Display peek");
        while (true) { 
            System.out.print("Enter your choice : ");
            choice = sc.nextInt();
            switch(choice) {
                case 1 ->  {
                    System.out.print("Enter element to push : ");
                    int ele = sc.nextInt();
                    stack.push(ele);
                }
                case 2 -> stack.pop();
                
                case 3 -> stack.printStack();

                case 4 -> stack.peek();
            }
        }
    }
}

Common Stack Operations (Conceptual)

  • push(value) – add an element to the top.
  • pop() – remove and return the top element.
  • peek() – view the top element without removing it.
  • isEmpty() – check if the stack has no elements.

These operations are typically O(1) in both array‑based and linked‑list‑based stacks.

Queue

A queue is a FIFO (First In, First Out) data structure. The first element added is the first to be removed.

Java 
import java.util.LinkedList;
import java.util.Queue;

Queue<Integer> queue = new LinkedList<>();
queue.offer(10);
queue.offer(20);
queue.offer(30);

System.out.println(queue.poll()); // 10
System.out.println(queue.peek()); // 20

Sorting algorithms arrange elements in a specific order (ascending or descending).

Java — Bubble Sort 
void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

Searching Algorithms

Searching algorithms locate a specific element within a data structure.

Java — Binary Search 
int binarySearch(int[] arr, int target) {
    int left = 0, right = arr.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}

Two Pointer Algorithm

The Two Pointer Algorithm is a technique used to solve problems that involve searching for pairs of elements in a sorted array or linked list. It uses two pointers that start at opposite ends of the data structure and move towards each other based on certain conditions.
