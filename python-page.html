Introduction to Python

Python is a high-level, interpreted, and dynamically typed programming language known for its simplicity and versatility. It supports multiple programming paradigms, including procedural, object-oriented, and functional programming.

Basic Syntax

Python code is executed line by line. Unlike Java or C++, indentation determines code blocks instead of curly braces.

Python 
print("Hello, World!")

if True:
    print("This is indented properly!")

Data Types

Python supports several built-in data types: int, float, str, list, tuple, dict, and set.

Python 
name = "Alice"       # str
age = 25             # int
pi = 3.14            # float
numbers = [1, 2, 3]  # list
person = {"name": "Alice", "age": 25}  # dict

Loops & Control Flow

Python provides for and while loops to iterate over sequences.

Python 
# For loop
for i in range(5):
    print("Iteration:", i)

# While loop
count = 0
while count < 3:
    print("Count:", count)
    count += 1

Functions

Functions in Python are defined using the def keyword. They enable reusability and modular coding.

Python 
def greet(name):
    return f"Hello, {name}!"

print(greet("Alice"))

Output

Hello, Alice!

Object-Oriented Programming

Python supports classes and objects. You can create classes using the class keyword.

Python 
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print(f"Hello, I'm {self.name} and I'm {self.age} years old.")

p1 = Person("Bob", 30)
p1.greet()

Output

Hello, I'm Bob and I'm 30 years old.

Lambda Functions

A lambda function is an anonymous (unnamed) function used to write small, one-line functions without formally defining them using def. It's best thought of as a shortcut for creating a function when you only need it for a small task.

Python 
def square(x):
    return x * x

# is the same as:
square = lambda x: x * x

print(square(5))

Output

25

Lambda Syntax

The general form of a lambda function is:

Python 
lambda parameters : expression

Unlike a normal function, return is implicit — the result of the expression is returned automatically. Lambda functions are limited to a single expression, which is why they're best suited for short, simple logic.

Lambda vs Normal Function

Python 
# Normal function
def multiply(a, b):
    return a * b

print(multiply(10, 20))

# Lambda function
multiply = lambda a, b: a * b

print(multiply(10, 20))

Output

200
200

Lambda with map()

map() applies a function to every element of a sequence.

Python 
numbers = [1, 2, 3, 4, 5]

result = list(map(lambda x: x * x, numbers))

print(result)

Output

[1, 4, 9, 16, 25]

Lambda with filter()

filter() keeps only the elements for which the lambda returns True.

Python 
numbers = [1, 2, 3, 4, 5, 6]

even = list(filter(lambda x: x % 2 == 0, numbers))

print(even)

Output

[2, 4, 6]

Lambda with reduce()

reduce() repeatedly combines elements of a sequence into a single result.

Python 
from functools import reduce

numbers = [1, 2, 3, 4]

result = reduce(lambda x, y: x + y, numbers)

print(result)

Output

10

Lambda with sorted() / sort()

Lambdas are commonly used as the key function for custom sorting.

Python 
students = [("Ram", 70), ("John", 95), ("Sam", 80)]

students.sort(key=lambda x: x[1])

print(students)

Output

[('Ram', 70), ('Sam', 80), ('John', 95)]

Lambda with max() / min()

Python 
students = [("Ram", 70), ("John", 95), ("Sam", 80)]

highest = max(students, key=lambda x: x[1])

print(highest)

Output

('John', 95)

When to Use Lambda

Use a lambda when the function is short, used only once, passed as an argument, or used with map(), filter(), sorted(), max(), or min(). Avoid lambdas when the logic is long, requires multiple statements, loops, or try/except, or when the function will be reused in many places — a named function is clearer in those cases.

Modules & Packages

Modules are files containing Python code. You import them using the import statement.

Python 
import math

print(math.sqrt(16))  # Output: 4.0

Exception Handling

Python handles runtime errors using try, except, and finally blocks.

Python 
try:
    num = int(input("Enter a number: "))
    print(10 / num)
except ZeroDivisionError:
    print("Cannot divide by zero!")
except ValueError:
    print("Invalid input.")
finally:
    print("Execution complete.")

File Handling

Python provides simple built-in functions for file operations.

Python 
# Writing to a file
with open("example.txt", "w") as file:
    file.write("Hello, Python!")

# Reading from a file
with open("example.txt", "r") as file:
    print(file.read())
